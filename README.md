# GROW — A Living System

An interactive STEM biology game about plant growth, environmental variables, and system thinking.

## STEM Information

- **STEM topic:** Plant Growth
- **STEM branch:** Science / Biology
- **Game format:** Interactive browser simulation

## How to Play

Adjust water, light, temperature, and nutrients only when the plant needs them. Changes settle gradually as days pass. Read the plant's signals, then use **LET ONE DAY PASS** to observe the next stage of growth.

The game includes seasonal environments, gradual plant development, health feedback, and an About Game panel with the learning outcomes.

## Learning Outcomes

- **A — Audience:** Students.
- **B — Behavior:** Identify how water, light, temperature, and nutrients affect plant growth.
- **C — Condition:** After observing plant signals and adjusting one environmental variable in the simulation.
- **D — Degree:** Correctly explain at least 3 relationships and maintain plant health at 60 or above during a 7-day simulation.

## Run Locally

Open `index.html` in a browser. The game uses only HTML, CSS, and JavaScript, so no build step is required.
